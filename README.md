# Rang One – native Android browser (v4.7)

Rang One is a light native web browser by PlayRang Technologies (India).
Native Java app (minSdk 24, targetSdk 34): tabs + tab switcher, private tabs, bookmarks, history, downloads (Android DownloadManager), offline pages, find in page, desktop site, share, Hindi/English home screen with speed dial, settings (search engine, theme, language, clear data) and an About screen.

Permissions: INTERNET, ACCESS_NETWORK_STATE only. No login, no ads, no analytics. All user data stays on the device.

Privacy policy: https://mannukumarbank222-cmd.github.io/rang-studio/privacy-policy-rang-one.html

Built by GitHub Actions on every push to `main`; the signed APK and real emulator screenshots are attached to Releases.
